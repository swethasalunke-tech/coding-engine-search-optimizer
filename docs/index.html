Coding-Agent-Search-Optimizer

SEO, but for coding agents: making sure the solutions your agent decides on actually get used.

What it does

Give it a recorded coding-agent session (a transcript) and the diff that session produced, and it checks whether the agent actually followed through on the solutions it said, mid-conversation, it would apply — instead of drifting, contradicting itself, or silently abandoning its own earlier plan. This is a known, documented failure mode (sometimes called context rot or plan decay) in long agent sessions.

It's a different question from what trajectory benchmarks like SWE-bench or TRAJECT-Bench answer — those check an agent's output against an external reference plan. This checks an agent's self-consistency against its own stated plan.

Free, foreverSingle-session CLI audit

The full audit pipeline — stated-solution extraction, diff parsing, adherence classification, a markdown report — runs locally, with no license, no account, and no network call required. 

python -m solution_optimizer.cli audit --transcript session.json --diff session.diff
